This page is `pages/index.md`. Every markdown file in `pages/` is a page, at the address its path names:
`pages/about.md` is [/about/](/about/).

What it looks like comes from the style guide, `__PD_SITE_PACKAGE__`: a page that names no layout renders with its
`layouts/page`, inside its `partials/base`. To change the look, change the style guide; this site holds the words.
