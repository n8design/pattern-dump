# Fonts

The skin's two families, self-hosted. Both are licensed under the SIL Open Font License 1.1; each
family's licence sits next to its files. The files are the upstream releases, unmodified (only renamed),
so the reserved font name in Source Serif's licence is respected.

| `source-serif-4-italic.woff2` | Source Serif 4 Italic, variable weight and optical size | [adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif) `WOFF2/VAR/SourceSerif4Variable-Italic.ttf.woff2` at `80d3f88` |
