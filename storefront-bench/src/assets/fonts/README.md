# Fonts

The skin's three families, self-hosted. Both are licensed under the SIL Open Font License 1.1; each
family's licence sits next to its files. The files are the upstream releases, unmodified (only renamed),
so the reserved font names in Source Serif's and IBM Plex's licences are respected.
